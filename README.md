# Конвертер последовательностей изображений в видео

Streamlit-приложение группирует последовательности изображений из выбранной
папки и создаёт из них видеофайлы. Прогресс обработки отображается в веб-интерфейсе.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

На Windows окружение активируется командой `.venv\Scripts\activate`.

Для создания видео в системе также должен быть доступен FFmpeg.

## Запуск

```bash
streamlit run main.py
```

В открывшемся интерфейсе укажите существующую папку с изображениями и
существующую папку для готовых видео, затем нажмите «Конвертировать».

Временные каталоги `*_temp` создаются во время обработки и исключены из Git.
